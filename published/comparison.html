Следующий шаг зависит от исхода проверки. Если validate сообщает о сбое, к пробному запуску не переходите и действуйте по разделу «Остановка». Если сбоя нет, переходите к пробному запуску.

## Пробный запуск

Пробный запуск использует команду run с флагом --dry-run для того же файла:

```
northctl run --dry-run input.ndjson
```

Режим dry-run не изменяет данные. Основной запуск отличается от пробного только тем, что в его команде нет флага --dry-run.

После пробного запуска переходите к выполнению.

## Выполнение

Запустите основную команду:

```
northctl run input.ndjson
```

Во время выполнения для запросов действуют ограничения. Максимальный размер запроса — 8 МиБ. Таймаут запроса — 30 секунд.

При временных сбоях отправку можно повторить. Clients may retry temporary failures. Повторная отправка допускается не более 3 раз.

Учитывайте, как сохраняются события с одинаковым ID. Ключ дедупликации хранится 24 часа. Первое событие с данным ID сохраняется. Повторный ID не заменяет первое событие.

Правило о журнале действует и на этом шаге: секреты в журнал не записывайте. После выполнения переходите к проверке результата.

## Проверка результата

Проверьте результат командой:

```
northctl verify receipt.json
```

Это последняя команда процедуры. Если verify сообщает о сбое, действуйте по разделу «Остановка». Если сбоя нет, все команды процедуры выполнены.

Архив хранится 14 дней. Удаление архива запрещено. Запрет не зависит от исхода проверки: архив нельзя удалять ни после успешной проверки, ни после остановки.

## Остановка

Сбой проверки означает остановку. Применяйте это правило на шаге проверки входа, где работает validate, и на шаге проверки результата, где работает verify.

Остановка значит, что следующие команды процедуры вы не выполняете. Если сбой произошёл при проверке входа, не запускайте ни пробный запуск, ни выполнение. Если сбой произошёл при проверке результата, процедуру не продолжайте.

Остановка не отменяет общих правил. Проверку TLS не отключайте. Секреты в журнал не записывайте. Архив не удаляйте.
