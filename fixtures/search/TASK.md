Выполни это полностью утверждённое синтетическое задание без дополнительных вопросов. Разрешены только локальные исходники и встроенные инструменты. Не используй сеть, делегирование другим моделям, git commit/push, изменение глобальных настроек, получение credentials или создание work items. Эта копия принадлежит supervised benchmark runner в рамках задачи 34; никакие production операции не нужны. Работай только внутри текущего каталога. Заверши процесс после результата.

Найди ответы в docs/. Используй только действующий регламент; архив и background не задают актуальные значения.
Контракт поиска v2: id и line — целые JSON-числа, не boolean и не дробные числа. Создай result.json — массив из 12 объектов в порядке вопросов: {"id":1,"answer":"строка","evidence":[{"file":"docs/01-current.md","line":4}]}.
answer должен содержать только запрошенное значение без единиц и пояснений; для да/нет используй «запрещено» или «обязательна» по смыслу.
Если данных нет, answer="не найдено", evidence=[]. Для найденного ответа приведи ровно одну строку источника, нумерация с 1.
