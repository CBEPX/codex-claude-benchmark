# Инструкция оператора: процедура сервиса «Север»

Эта инструкция предназначена для оператора, который выполняет процедуру впервые. Проходите разделы строго по порядку и не переходите к следующему разделу, пока не завершён текущий. Команды приведены в том порядке, в котором их нужно выполнять.

## Подготовка

Сервис называется «Север». Версия протокола — 2.4. Владелец процедуры — platform-ops. Время указывается в Europe/Moscow. Используйте это правило для всех отметок времени, которые встречаются в ходе процедуры.

Перед началом ознакомьтесь с ограничениями, которые действуют на всех последующих шагах. Максимальный размер запроса — 8 МиБ. Таймаут запроса — 30 секунд. Повторная отправка допускается не более 3 раз. Clients may retry temporary failures. Ключ дедупликации хранится 24 часа.

Требования безопасности действуют на протяжении всей процедуры. Проверка TLS обязательна. Clients must not disable TLS verification. Секреты нельзя записывать в журнал.

Правила для архива также действуют всё время. Архив хранится 14 дней. Удаление архива запрещено.

Когда вы ознакомились с ограничениями и требованиями, переходите к проверке входа.

## Проверка входа

Сначала убедитесь, что понимаете правила обработки входных данных. Входной файл имеет формат NDJSON. Пустые строки пропускаются. Первое событие с данным ID сохраняется. Повторный ID не заменяет первое событие. Эти правила помогут правильно понимать, как будут обработаны события из файла.

Выполните проверку входного файла:

```
northctl validate input.ndjson
```

Если проверка входа завершилась сбоем, не переходите к пробному запуску: сразу перейдите к разделу «Остановка». Если проверка прошла без сбоя, переходите к пробному запуску.

## Пробный запуск

Пробный запуск выполняется после успешной проверки входа и до основного выполнения. Режим dry-run не изменяет данные. Поэтому этот шаг безопасен для данных.

Выполните пробный запуск с тем же входным файлом:

```
northctl run --dry-run input.ndjson
```

После завершения пробного запуска переходите к выполнению. Не пропускайте этот шаг и не меняйте порядок команд.

## Выполнение

Основной запуск выполняйте только после проверки входа и пробного запуска. В отличие от пробного запуска, эта команда выполняется без режима dry-run.

Выполните основной запуск:

```
northctl run input.ndjson
```

Если возник временный сбой, повторная отправка возможна, но только в пределах ограничения, указанного в разделе «Подготовка». При повторной отправке по-прежнему не отключайте проверку TLS и не записывайте секреты в журнал.

После завершения выполнения переходите к проверке результата.

## Проверка результата

Проверьте результат выполнения по файлу receipt.json:

```
northctl verify receipt.json
```

Если проверка результата завершилась сбоем, перейдите к разделу «Остановка». Если проверка прошла без сбоя, все команды процедуры выполнены в заданном порядке и процедура завершена.

## Остановка

Сбой проверки означает остановку. Это правило относится и к проверке входа, и к проверке результата. При остановке не выполняйте команды, которые идут после проверки, завершившейся сбоем.

Во время остановки продолжают действовать общие требования из раздела «Подготовка»: архив удалять нельзя, секреты нельзя записывать в журнал, а проверку TLS нельзя отключать.
