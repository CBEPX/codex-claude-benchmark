# Процедура northctl для сервиса «Север»

## Подготовка

Процедура состоит из последовательных шагов: проверка входа, пробный запуск, выполнение и проверка результата. Выполняйте команды в порядке разделов этой инструкции и не пропускайте шаги. Раздел «Остановка» описывает, когда процедуру нужно прервать.

Перед первой командой ознакомьтесь с исходными данными:

- Сервис называется «Север».
- Версия протокола — 2.4.
- Владелец процедуры — platform-ops.
- Время указывается в Europe/Moscow.

Следующие правила безопасности действуют на всех шагах, включая остановку:

- Проверка TLS обязательна.
- Clients must not disable TLS verification. (Клиенты не должны отключать проверку TLS.)
- Секреты нельзя записывать в журнал.

## Проверка входа

На этом шаге команда validate проверяет входной файл input.ndjson до того, как процедура начнёт с ним работать. Входной файл имеет формат NDJSON. Пустые строки пропускаются.

Выполните проверку входа:

```sh
northctl validate input.ndjson
```

Если проверка прошла без сбоя, переходите к разделу «Пробный запуск». Если проверка завершилась сбоем, не выполняйте следующие команды и перейдите к разделу «Остановка».

## Пробный запуск

Режим dry-run не изменяет данные. Команда этого шага отличается от команды раздела «Выполнение» только флагом --dry-run.

Выполните пробный запуск:

```sh
northctl run --dry-run input.ndjson
```

После пробного запуска переходите к разделу «Выполнение».

## Выполнение

На этом шаге запустите ту же команду без флага --dry-run:

```sh
northctl run input.ndjson
```

Во время выполнения действуют ограничения на запросы:

- Максимальный размер запроса — 8 МиБ.
- Таймаут запроса — 30 секунд.

Правила повторной отправки:

- Clients may retry temporary failures. (Клиенты могут повторять отправку при временных сбоях.)
- Повторная отправка допускается не более 3 раз.

Повторная отправка — это разрешение, а не обязательный шаг. Если вы её используете, соблюдайте указанный лимит.

Правила дедупликации:

- Ключ дедупликации хранится 24 часа.
- Первое событие с данным ID сохраняется.
- Повторный ID не заменяет первое событие.

Когда команда выполнения завершится, переходите к разделу «Проверка результата».

## Проверка результата

На этом шаге команда verify проверяет файл receipt.json. Это последняя команда процедуры.

Выполните проверку результата:

```sh
northctl verify receipt.json
```

Если проверка прошла без сбоя, процедура завершена. Если проверка завершилась сбоем, перейдите к разделу «Остановка».

Архив хранится 14 дней. Удаление архива запрещено. Не удаляйте архив ни после успешной проверки, ни после сбоя.

## Остановка

Сбой проверки означает остановку. Это правило относится к шагам проверки: к проверке входа командой validate и к проверке результата командой verify.

При остановке:

- не выполняйте следующие команды процедуры;
- не отключайте проверку TLS;
- не записывайте секреты в журнал;
- не удаляйте архив.

Для пробного запуска и выполнения процедура отдельных условий остановки не устанавливает. Временные сбои во время выполнения подчиняются правилам повторной отправки из раздела «Выполнение». Действия после исчерпания лимита повторов и после остановки процедура не определяет.
