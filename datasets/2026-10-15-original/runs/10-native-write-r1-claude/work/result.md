## Подготовка

Эта инструкция предназначена для оператора, который впервые выполняет процедуру. Она описывает шаги по порядку и объясняет, когда переходить к следующему шагу, а когда останавливаться.

Основные сведения:

- Сервис называется «Север».
- Владелец процедуры — platform-ops.
- Версия протокола — 2.4.
- Время указывается в Europe/Moscow.

Процедура состоит из последовательных шагов: проверка входа, пробный запуск, выполнение и проверка результата. Для каждого шага используется своя команда northctl. Команда validate относится к проверке входа, режим dry-run к пробному запуску, команда run к выполнению, а команда verify к проверке результата. Выполняйте команды в том порядке, в котором они приведены в разделах этой инструкции.

В процедуре используются входной файл input.ndjson и файл receipt.json, который передаётся команде проверки результата. Переход к следующему шагу описан в конце каждого раздела. Условие остановки и действия после неё описаны в разделе «Остановка».

Правила безопасности действуют на всех шагах:

- Проверка TLS обязательна.
- Clients must not disable TLS verification.
- Секреты нельзя записывать в журнал.

## Проверка входа

На этом шаге проверяется входной файл input.ndjson. Сведения о входном файле:

- Входной файл имеет формат NDJSON.
- Пустые строки пропускаются.

Запустите проверку входа:

```
northctl validate input.ndjson
```

Дальнейший порядок зависит от итога команды. Если проверка завершилась без сбоя, переходите к разделу «Пробный запуск». Если проверка завершилась сбоем, следующие команды не запускайте и перейдите к разделу «Остановка».

## Пробный запуск

Пробный запуск использует тот же входной файл, что и проверка входа. Режим dry-run не изменяет данные. В порядке процедуры этот шаг стоит перед основным запуском.

Запустите пробный режим:

```
northctl run --dry-run input.ndjson
```

После пробного запуска переходите к разделу «Выполнение». Команда основного запуска отличается от команды пробного только тем, что в ней нет флага --dry-run.

## Выполнение

Выполните основной запуск с тем же входным файлом:

```
northctl run input.ndjson
```

Параметры запросов и повторной отправки:

- Максимальный размер запроса — 8 МиБ.
- Таймаут запроса — 30 секунд.
- Повторная отправка допускается не более 3 раз.
- Clients may retry temporary failures.

События с одинаковым ID обрабатываются по таким правилам:

- Первое событие с данным ID сохраняется.
- Повторный ID не заменяет первое событие.
- Ключ дедупликации хранится 24 часа.

После завершения команды переходите к разделу «Проверка результата».

## Проверка результата

Проверьте результат по файлу receipt.json:

```
northctl verify receipt.json
```

Если проверка завершилась без сбоя, процедура выполнена полностью: это последняя команда. Если проверка завершилась сбоем, перейдите к разделу «Остановка».

Сведения об архиве:

- Архив хранится 14 дней.
- Удаление архива запрещено.

## Остановка

Сбой проверки означает остановку. Это правило относится к обоим шагам проверки: к проверке входа и к проверке результата.

Остановка означает, что следующие команды процедуры не запускаются:

- при сбое проверки входа не выполняйте ни пробный запуск, ни выполнение;
- при сбое проверки результата процедура заканчивается на этом шаге.

При остановке продолжают действовать правила из предыдущих разделов: секреты не записываются в журнал, а архив не удаляется.
